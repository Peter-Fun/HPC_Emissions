# High Powered Computing Emissions

This project is a mathematical model representing the carbon emissions from high powered computing data centers.

The model includes factors such as construction, electricity energy mixes, capacity of racks and servers, power usage effectiveness, and average utilization rate into how much power is used for the centers and how much carbon is emitted from generating that power. 

Extrapolating the current trend of energy types between renewables and nonrenewables allows the model to predict future carbon emissions. Other metrics such as land use and energy cost were similar calculated from extrapolations of current trends. This model predicts up to 2030.

The source code and graphical displays of trends can be viewed in the jupyter notebook.
